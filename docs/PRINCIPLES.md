# PRINCIPLES — Coded Atlas

## Produto

1. Media-first.
2. Project-first.
3. Local-first.
4. Deterministic where possible.
5. AI where judgment matters.
6. User remains in control.
7. Progressive disclosure.
8. Output quality over feature count.

## Engenharia

1. Domain before infrastructure.
2. Runtime validation is mandatory.
3. Heavy work runs as jobs.
4. Files are assets, not random paths.
5. IDs are identity; slugs are labels.
6. Immutable media artifacts.
7. Transactional writes.
8. Explicit errors and warnings.
9. Safe cancellation.
10. No silent degradation.
11. Adapters around external technologies.
12. Migration over rewrite.

## Criatividade

1. Curated systems beat arbitrary generation.
2. Composition definitions beat one-off layouts.
3. Motion presets beat keyframe complexity in V1.
4. Project identity must survive Coded by M styling.
5. A Media Kit shares one Creative Direction.
6. Avoid AI slop.

## UX

1. Quick first.
2. Edit only when needed.
3. Animate only when needed.
4. Never block UI on render.
5. Show actual job state.
6. Preserve user work.
7. Undo/redo in editable documents.
8. Controls appear only when relevant.
