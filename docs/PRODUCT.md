# PRODUCT — Coded Atlas

## Definição

O Coded Atlas é uma ferramenta interna da Coded by M para **capturar, entender, compor, animar, renderizar e publicar mídia derivada de produtos digitais**.

## Usuário principal

Coded by M. O produto deve otimizar o fluxo real do estúdio, não necessidades hipotéticas de um SaaS multiusuário.

## Entradas

- Website URL
- GitHub repository
- projeto local
- build local
- upload manual de assets

## Saídas

- screenshots e full-page captures;
- section/state/device/motion captures;
- thumbnails e mockups;
- social posts, stories e carrosséis;
- reels e showcase videos;
- apresentações;
- case studies;
- portfolio assets;
- client packages.

## Domínios

### Import
Cria/atualiza Sources.

### Capture
Produz matéria-prima visual.

### Understand
Consolida identidade e contexto em `VisualProfile`.

### Create
Produz planos, composições e documentos.

### Render
Transforma documentos em arquivos finais.

### Publish
Organiza Outputs em pacotes e destinos.

## Atlas Brain

Atua como **Creative Director**.

Responsabilidades: seleção de assets, direção criativa, composição, storyboard, Media Kit e refinamento.

Não é responsável por resize físico, captura, render, FFmpeg, filesystem, banco ou publicação autônoma.

## Experiência principal

```text
Projects
↓
Open Project
↓
Generate Media Kit
↓
Review Creative Plan
↓
Generate
↓
Edit if needed
↓
Render
↓
Export
```

## Product principles

- progressive disclosure;
- project-first navigation;
- outputs consistentes;
- design system Coded by M;
- zero dashboards decorativos;
- estado real, não loading fake;
- operações longas sempre como jobs;
- nenhuma feature nova deve quebrar o fluxo principal.
