# VISION — Coded Atlas

## North Star

**Coded Atlas transforma produtos digitais em mídia.**

O valor do Atlas não está em tirar screenshots. Está em reduzir a distância entre projeto digital finalizado e material visual profissional pronto para apresentar.

## Problema

Depois de finalizar um site ou software, ainda existe trabalho manual para capturar desktop/mobile, escolher telas, montar mockups, criar posts, gravar vídeos, montar carrosséis/apresentações/cases e preparar assets para portfólio.

O Atlas transforma essa pós-produção em um sistema.

## Futuro desejado

```text
Import project
↓
Atlas captures and organizes
↓
Atlas understands the visual identity
↓
User requests a goal
↓
Atlas Brain creates a creative plan
↓
Composition/Motion engines execute
↓
User reviews
↓
Atlas renders and exports the complete package
```

Exemplo:

```text
"Quero lançar esse projeto."

↓

3 social posts
1 carousel
2 stories
1 reel
1 portfolio hero
1 presentation
```

## Princípios

1. Media-first.
2. Local-first.
3. Automação antes de edição manual.
4. Curadoria antes de geração arbitrária.
5. Preview rápido antes de render pesado.
6. IA como direção criativa, não como infraestrutura.
7. Um projeto gera múltiplos formatos com identidade consistente.
8. 80% das peças devem ser produzíveis sem editor avançado.
9. O usuário sempre pode assumir controle manual.
10. O Atlas continua útil sem IA.

## Fronteira

O Atlas termina onde começa engenharia de software. Ele pode ler um repositório para localizar assets, metadata e contexto visual, mas não deve evoluir para revisar ou corrigir código.
